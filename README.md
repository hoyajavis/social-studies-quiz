# Social Studies Quiz Master 🌍 📜

**Social Studies Quiz Master** is an interactive, web-based study application designed to help 6th-grade students master Ancient Civilizations and Geography vocabulary. Built with gamification in mind, the app ensures students thoroughly learn terms through four distinct testing modes.

## ✨ Features

- **Four Progressive Quiz Modes:**
  1. 🎧 **Spelling Challenge:** Listen to the word read aloud via Text-to-Speech and type the correct spelling.
  2. 📖 **Core Definitions:** Identify the correct vocabulary word from its full definition.
  3. 🧩 **Contextual Usage (Unlockable):** Fill in the blank using context clues from example sentences.
  4. 🧠 **Deep Concept Mastery (Unlockable):** Master granular components of the definition by filling in the blanks.
- **Progression System:** Students must score 70% or higher to unlock the more advanced, contextual game modes.
- **Engaging Feedback:** Features custom sparkle animations and sound effects using the Web Audio API for correct and incorrect answers.
- **Local Persistence:** High scores and unlocked levels are automatically saved in the browser's `localStorage`.

## 📚 Vocabulary Chapters

- **Chapter 1:** Foundations (Vocabulary List #1)
- **Chapter 2:** Ancient Civilizations (Vocabulary List #2)

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS (v4)
- **Animations:** Framer Motion (`motion/react`)
- **Icons:** Lucide React

## 🚀 Getting Started

To run this project locally:

**Prerequisites:** Node.js installed on your machine.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hoyajavis/social-studies-quiz.git
   cd social-studies-quiz
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
